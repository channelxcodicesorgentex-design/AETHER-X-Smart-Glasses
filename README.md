# 🕶️ AETHER-X: Open-Source Modular Smart Glasses

Benvenuto nella repository ufficiale di **AETHER-X**, il progetto di smart glasses fai-da-te, modulare e open-source pensato dai maker per i maker! 🚀

---

## 🎯 La Filosofia del Progetto
A differenza delle soluzioni commerciali chiuse e costose, **AETHER-X** nasce per offrire un'alternativa accessibile, trasparente e completamente personalizzabile. Vogliamo unire l'estetica e le funzioni dei moderni HUD tattici alla libertà della programmazione open-source.

---

## 🛠️ Hardware Utilizzato
* **Microcontrollore**: ESP32-CAM (con modulo Wi-Fi/Bluetooth e videocamera OV2640 integrata).
* **Display HUD**: Display OLED 128x64 (driver SSD1306/SSD1315, connessione I2C).
* **Ambiente di Sviluppo**: ArduinoDroid (IDE mobile) / Arduino IDE.

---

## 📂 Struttura della Repository
* **`firmware/`**: Codici sorgente per l'ESP32.
  * `01-OLED-Test/`: Test di base e inizializzazione del display I2C.
  * `02-ESP32-CAM/`: Gestione della telecamera e flussi di dati.
* **`docs/`**: Schemi di collegamento elettrico, guide di assemblaggio e documentazione hardware.

---

## 🚀 Roadmap
1. **Fase 1**: Test hardware e accensione del display OLED.
2. **Fase 2**: Integrazione della telecamera OV2640 e streaming locale.
3. **Fase 3**: Sviluppo della dashboard HUD interattiva e dei mini-menu.
4. **Fase 4**: Rilascio di funzioni avanzate e apertura alla community globale per nuove mod!
